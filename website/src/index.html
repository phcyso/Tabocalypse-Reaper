Features

Everything you need to tame your tab horde

🗂️

Smart Grouping

Automatically organizes tabs into Host → Cluster hierarchy. GitHub repos, AWS docs, and generic sites all get special treatment.

⚡

Bulk Actions

Reap entire groups with one click! Close all tabs from a host, cluster, or cherry-pick individual tabs. Safety confirmation for 10+ tabs.

🎨

Theme Adaptive

Beautiful purple theme that adapts to your browser's light/dark mode preferences. Looks great everywhere.

🔍

Quick Filter

Search across hosts, paths, and titles. Filter results instantly. Option to exclude pinned tabs from view.

🪟

Cross-Window

Works across all your Firefox windows. See and manage tabs from everywhere in one unified view.

🚀

Zero Dependencies

Built with vanilla TypeScript. No runtime dependencies means fast loading and minimal resource usage.

Installation

Get reaping in under 2 minutes

🔧 Developer Installation (Temporary)

  1. 1 Download or clone the GitHub repository
  2. 2 Run npm install and npm run prepare
  3. 3 Open Firefox and navigate to about:debugging#/runtime/this-firefox
  4. 4 Click "Load Temporary Add-on…" and select dist/manifest.json
  5. 5 Start reaping! 💀

Note: Temporary add-ons are removed when Firefox restarts. We're working on getting published to Firefox Add-ons!
